# Reused presentation

Adapted from Expressive Island's Installer Helper: responsive Compose layout, Google Sans Flex
variable typography, Clock Concept teal palette, charcoal status surface, press illumination,
mechanical download progress, reduced-motion support, connection settings and light/dark themes.
Clock-specific branding, repository and verified build metadata replace Island text. The standalone
app is labelled Expressive Clock Installer Helper. The title inside the page is Clock Installer.

The deliberate interaction difference is the standard Android package-install session, replacing
Island's optional external APK-viewer preference. This gives a reliable Android completion callback.
No production Clock components are changed or linked at runtime. See README.md for security/setup.
