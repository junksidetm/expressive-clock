# v0.1.5 source inventory

Compared with `v0.1.4`; includes committed post-tag widget/landscape/terms changes and the reviewed subsequent local development. Historical reports describe intermediate designs; final source and release notes take precedence.

## Scope decisions

- Main app source and focused regression tests are included. No generated palettes, SDK/dependency updates or package identity changes.
- Installer Helper is a separate Gradle root/application. It is retained with source, tests, license notices and dispatch-only artifact tooling; the production root includes only `:app`.
- `app/src/debug` is deliberate test instrumentation, not production functionality. Its manifest/probe is excluded by the release source set and verified absent from the signed manifest. No prototype widget font resolver remains.
- `app/release/`, all Gradle build outputs, APK/AAB/DM files and Python caches are excluded by ignore rules and remain local.
- Keystore properties, keystores, local SDK properties, delivery/ntfy config and authentication credentials are excluded. Public debug package/certificate trust anchors are not secrets.
- Historical prototype/findings documentation is retained as research evidence; it does not introduce prototype source into production.
